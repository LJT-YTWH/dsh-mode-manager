# dsh-mode-manager

**给 DeepSeek Harness 左侧栏加一个「模式管理」页：可视化创建、编辑、删除 Agent 预设（模式），
删除后还能扫描并修复受影响的旧会话。**

包名 `@local/dsh-mode-manager` 是本地私有 bundle，不发布到 npm。它不改 DSH 安装包与官方预设源文件，
只通过 DSH 的 bundle 机制接入。

## 功能

- **预设列表**：列出全部 Agent 预设，显示来源徽章（官方 / 自建 / 已自定义 / 未托管 / 已损坏）、
  默认标记，以及当前记录使用该预设的会话数；支持按官方 / 自建 / 已损坏过滤和搜索。
- **查看组合**：以只读 YAML 展示任意预设的完整内容，支持复制；自建预设额外显示包名与目录。
- **四步创建向导**：起点（Standard / Minimal / 空白 / 复制现有 / 导入官方模式）→ 基本信息（名称、id、描述、顺序）
  → 能力勾选（文件读写编辑/图片/补丁/搜索、命令与持久终端、网页搜索与抓取、子代理控制/委派/Fork/工作流、
  计划模式、技能目录与加载、待办/任务/日程/目标/提问/展示/Office、插件管理/市场/Cordis/PTC 执行器、时间/AGENTS.md）
  与人设（每项能力下都有一句中文说明，告诉你它对应哪个官方工具）→ YAML 预览并安装生成的自建 bundle；
  也可选择「导入官方模式」，
  把官方模式（标准/PTC/极简/创造）的插件组合原样复制成自己的模式（导入后组合只读）。
- **编辑与设为默认**：编辑自建预设（id 锁定），把任意健康预设设为默认。
- **删除与自动备份**：删除自建预设前必须勾选确认，系统先备份再删除；删除后立即扫描受影响会话。
- **扫描与修复**：按项目分组列出使用过该预设的会话（含已归档、运行中、子代理标记），可批量替换为
  另一个预设；支持进度、取消、失败项重试 / Fork 到新模式 / 跳过。
- **旧会话提示**：打开模式已被删除的旧会话时弹窗提示，可单独修复当前会话。
- **备份与诊断**：页面底部可恢复备份、**删除单份备份**、清理旧备份（保留最近 20 份），并查看 DSH 版本、通信通道、
  修复通道可用性等诊断信息。
- **中英双语与主题适配**：跟随宿主语言显示中文或英文；界面使用 DSH 主题 token，亮暗主题一致。

## 安装

### 桌面版（DeepSeek Harness App）

1. 打开 **设置 → 插件 → 添加插件**。
2. 选择**本地目录**安装，目录指到本目录内的 `dsh-mode-manager/`（即 `package.json` 所在目录）。
3. 按提示启用 bundle。装好后左栏会出现「模式管理」入口。

> 桌面版的 `desktop` profile 由 App 独占管理，请走上面的图形界面安装，不要用 CLI 直接改该 profile。

### 其他 profile（CLI）

```sh
dsh plugin --profile <profile> add /绝对路径/dsh-mode-manager
```

本地目录安装是链接方式，安装后不要移动或删除这个目录。

## 使用流程

1. **进入页面**：点击左侧栏的「模式管理」。它是全局页，没有打开任何会话也能进入。
2. **创建模式**：点击「＋ 创建模式」，按四步向导选择起点、填写名称与 id、勾选能力并写人设，
   在第 4 步预览生成的 YAML 后点「创建」。
3. **新会话可见**：创建成功后，新模式出现在新会话的模式选择器中。已存在的会话保持原模式。
4. **编辑 / 删除**：自建卡片上有「查看 / 编辑 / 设为默认 / 删除」；官方 4 个预设
   （`standard`、`ptc`、`minimal`、`cordis`）只读，不可删除、不可编辑。
5. **修复受影响会话**：删除后若存在使用过该模式的会话，修复弹窗会自动打开；选择目标模式、
   勾选会话并开始修复。

## 删除与修复说明

- **删除不可逆**：删除只能通过自动备份恢复。确认弹窗要求勾选「我已了解删除后旧会话可能无法打开」，
  未勾选时删除按钮不可用。
- **默认模式不能删**：当前默认预设需要先切换到别的模式。
- **自动备份**：每次删除（以及编辑更新）都会把预设目录备份到 `~/.dsh/preset-backups/`。
  备份可在页面底部恢复，也可单独删除；删除备份只移除这份副本，不影响已安装的模式。
- **受影响扫描**：删除成功后，Host 端扫描记录使用该模式的会话，按项目分组返回；运行中的会话标记为
  暂不可修，子代理会话随父会话恢复、不单独修复。
- **修复是实验性通道**：修复会恢复旧会话、挂载目标预设，并把新的预设写回会话记录。它不改写历史消息；
  旧工具调用可能按新组合渲染。被其他写者占用的会话可能失败，按提示重试、Fork 或跳过即可。
- **只影响新会话**：编辑已有预设只影响新会话；旧会话在重新打开或重启后按新定义恢复。

## 数据存放位置

| 内容 | 位置 |
|---|---|
| 自建预设 bundle（`package.json`、`cordis.patch.yml`、`mode-manager.json`） | `~/.dsh/preset-creator/<id>/` |
| 操作审计日志 | `~/.dsh/preset-creator/audit.jsonl` |
| 删除 / 更新前的自动备份 | `~/.dsh/preset-backups/<id>-<timestamp>/` |

清理旧备份时默认保留最近 20 份；每一份备份也可单独删除。

## 卸载行为

- 卸载方式：**设置 → 插件** 找到本插件卸载；CLI profile 也可用
  `dsh plugin --profile <profile> remove @local/dsh-mode-manager`（以实际安装标识为准）。
- 卸载只移除「模式管理」入口，**不会删除你创建的模式**。自建预设是独立 bundle，仍会出现在新会话的
  模式选择器中。
- 备份目录 `~/.dsh/preset-backups/` 会保留。
- 如需彻底清理自建预设，请先在本插件里删除模式（会自动备份），再卸载本插件；不要直接手删
  `~/.dsh/preset-creator/` 下的目录，否则对应预设会变成「已损坏」。

- 修复通道依赖 DSH 内部会话接口，属于实验性能力，跨 DSH 大版本升级可能需要回归验证。

  Host 半在运行中的安装里做了两轮一次性自测：第一轮「生成→安装→修复冷会话→扫描→删除备份→恢复→Fork→设默认」
